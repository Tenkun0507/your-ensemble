# FOUR / ENSEMBLE 🎼

iPhoneのSafari / AndroidのChrome / パソコンで遊べる、4楽器のリズムゲーム。**外部ライブラリ・アカウント・サーバー・音声ファイル不要**の静的サイトなので、GitHub Pagesにそのまま公開できます。

## 遊び方

「ミ ミ ファ ソ ソ ファ ミ レ ド ド レ ミ レ ド ド」の15音に挑戦。全15音を1拍ごと（最後のドのみ2拍）に演奏します。BPMは100で、各パートの前に4拍のカウントがあります。

1. **🎹 ピアノ**：ノートが判定ラインに来た瞬間、正しい音程の鍵盤を押す。
2. **🥁 ドラム**：音程に関係なく、判定ラインに合わせて大きなパッドをタップ。
3. **🎺 トランペット**：左エリアを押したまま上下に動かして音程を選択。**右エリアも長押し**して発音。音程と持続率をチェック。
4. **🎻 ヴァイオリン**：左エリアをタップして音程選択。**右エリアを左右にスワイプ**して音を鳴らす。

全パートを演奏すると、それぞれの入力ログに基づく**合奏再生**と**総合採点**が解放されます。どの楽器も再挑戦できます。

判定：PERFECT ±45ms / GREAT ±85ms / GOOD ±135ms / MISS（左手の音程ミスもMISS）。総合点はパート平均85% + 4パートのタイミングの揃い具合15%。

## GitHub Pagesで公開する手順

1. GitHubにログインし、`New repository` から公開用のリポジトリ（例：`four-ensemble`）を作成します。**Public**を選ぶと通常の無料公開が分かりやすいです。
2. このフォルダの中身（`index.html`、`styles.css`、`game.js`、`README.md`、`.nojekyll`）を**リポジトリ直下に**アップロードしてコミットします。ZIPファイルそのものをアップロードするのではなく、**展開した各ファイルをアップロード**してください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** で **Source: Deploy from a branch** を選び、**Branch: `main` / `(root)`** を選択して **Save**。
5. GitHub Pagesの公開が完了したら、案内されたURLを**iPhoneのSafari**で開きます。通常のURL形式は `https://ユーザー名.github.io/four-ensemble/` です（リポジトリ名によって変わります）。

iPhoneでGitHubにファイルをアップロードするときにボタンが見つからない場合は、Safariの「デスクトップ用Webサイトを表示」を試してください。PCからのアップロードでも問題ありません。

### 「演奏スタート」が押せないとき

- `sandbox:` や ChatGPT の**ファイルプレビュー**ではなく、GitHub Pagesで公開した**`https://...github.io/.../` のURL**を Safari で直接開いてください。
- ページ上部のステータスが **「● ゲーム起動OK」** であることを確認してください。ステータスが変わらなければ `game.js` のアップロード先・ファイル名を確認します。
- iPhoneの消音スイッチや音量設定も確認してください。音はWeb Audio APIで合成します。
- Safariを閉じる・別のタブに移ると、演奏は安全のためリセットされます。

## 技術的な補足

Web Audio APIで音を合成し、`performance.now()`を基準にタイミングを判定します。スマートフォンで複数タッチできるようPointer Eventsを使用し、演奏パッドのスクロールを無効化しています。演奏記録はブラウザのページを開いている間のメモリにのみ保持します。外部への送信はありません。

> このゲームは指定された15音のメロディを使用しています。原曲音源や外部の素材は使用していません。
